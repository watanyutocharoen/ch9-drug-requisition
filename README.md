# ระบบเบิกยาห้องยา (Fixed stock)

แผนกเภสัชกรรม โรงพยาบาลจุฬารัตน์ 9 แอร์พอร์ต — ระบบคิดยอดเติม Fixed stock และออกใบเบิกรายสัปดาห์ของห้องยา M1, M2, ปกส., M4
แทนไฟล์ Excel "Fixed stock PHAR 3_Program"

## การทำงาน
1. ห้องยาอัปโหลดไฟล์ **Dispensing Summary (All Store)** จาก Centrix (เลือก Store ของห้องตัวเอง)
2. ระบบคิดยอดเติมแบบ Min-Max: เบิกทุกรอบที่คงเหลือต่ำกว่า Max โดยหลังเติมต้องไม่เกิน Max (ปัดลงเป็นหน่วยเบิก) ถ้าเติม 1 หน่วยเบิกแล้วเกิน Max = ยังไม่เบิก · Min = จุดเตือน
3. เภสัชกรตรวจ แก้ยอด แล้วอนุมัติ → ระบบบันทึกยอดยกไปให้รอบหน้า
4. พิมพ์ใบเบิก 4 แบบ: คลังยา / คลังยา-ขอซื้อ / TAM / TAM-ขอซื้อ
5. ห้องยากดยืนยันรับยา

## โครงสร้าง
- `index.html` — หน้าเว็บทั้งหมด (GitHub Pages)
- `seed-drugs.json` — รายการยาตั้งต้นจากไฟล์ Fixed stock PHAR 3 (ปุ่ม "โหลดรายการยาตั้งต้น" ในหน้าตั้งค่า)
- `supabase/functions/drugreq` — Edge Function (backend) ในโปรเจกต์ Supabase `ch9-supply`
- `supabase/migrations` — ตาราง `fs_*` (แยกจากข้อมูลระบบเบิกพัสดุ)

บัญชีพนักงานใช้ร่วมกับระบบเบิกพัสดุห้องยา (รหัสพนักงาน + รหัสผ่านเดียวกัน) แต่สิทธิ์ในระบบนี้ตั้งแยกในตาราง `fs_roles`:
เจ้าหน้าที่ / เภสัชกร (อนุมัติ) / ผู้ดูแลระบบ
